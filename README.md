# 📊 CryptoCurrency Tracker App

A simple and elegant **Android app** built with **Jetpack Compose** that lets you track real-time cryptocurrency prices, search for coins, and view market details.  
The app follows **MVVM architecture** and uses **Retrofit** for API calls, ensuring clean code structure and maintainability.  

---

## ✨ Features
- 🔍 Search and filter cryptocurrencies in real-time  
- 📈 View live market data with price updates  
- 🏗️ MVVM architecture with **Retrofit** integration  
- 📱 Lightweight and user-friendly design
